# DeepSeek V4 Flash 开发集评估：2026-09-06

本次实际运行了 companion 项目的 **ReActAgent + deepseek-v4-flash + calculator**，对 GSM8K 和 HotpotQA 的本地开发集各评估 400 题，每题一次。没有运行冻结测试集，没有使用 LLM 裁判，没有只重跑失败样本。

## 结果

| 数据集 | 指标 | 结果 | 有效评分 / 计划 |
|---|---|---:|---:|
| GSM8K | 数值正确率 | **91.48%（365/399）** | 399/400 |
| GSM8K | 格式合规率 | 97.74%（390/399） | 399/400 |
| HotpotQA | 答案完全匹配 EM | **57.25%（229/400）** | 400/400 |
| HotpotQA | 答案 F1 | **72.52%** | 400/400 |
| HotpotQA | 证据完全匹配 EM | 45.25%（181/400） | 400/400 |
| HotpotQA | 证据 F1 | **77.54%** | 400/400 |
| HotpotQA | 联合 EM | 29.50%（118/400） | 400/400 |
| HotpotQA | 联合 F1 | **60.04%** | 400/400 |
| HotpotQA | 格式合规率 | 96.75%（387/400） | 400/400 |

800 次任务均已结束并保存。GSM8K 有 1 次连接失败，保留在计划分母中，不伪造该题正确性分数；另有 7 题达到 4 步上限，这些题保留为 0 分。HotpotQA 没有执行失败。评分器本身无异常；连接失败的那题标记为无法评分。

GSM8K 数值正确率的题目级 Wilson 95% 区间为 **[88.33%, 93.84%]**；HotpotQA 答案 EM 为 **[52.36%, 62.01%]**。这些区间假设题目独立，不能覆盖所有共享文档/题型相关性。若按“所有计划任务中已确认正确”计数，GSM8K 为 365/400 = 91.25%；这是完成效果指标，与有效输出准确率 91.48% 的定义不同。

这是提供方响应中的实际 usage，不是按字符估算。输入中 775,040 token 为缓存命中，757,789 为缓存未命中；这些已经计入输入总量，不能再相加一次。1,440 次请求中有 1 次连接失败，未收到该次 usage，因此总用量是已知下界，不能当作精确账单。

从预检查开始到全部结束，墙钟时间 **307.5 秒（约 5 分钟）**，包含预检查后查看结果的间隔；两段执行会话共约 275.6 秒。任务执行耗时之和为 1,603.8 秒，并发执行使其大于墙钟时间。预检查的两题直接计入 800 题，没有额外重跑。

## 固定配置

- 提供方：DeepSeek 官方 API；请求和响应均记录 `deepseek-v4-flash`。
- 非思考模式：显式 `thinking.type=disabled`；temperature=0。
- 每题最多 4 个 Agent 步骤；每次 API 输出最多 2,048 token；累计 token 预算 20,000。
- HTTP timeout=60 秒；任务进程期限 270 秒；不自动重试 API 请求。
- 工具只有有界算术 calculator；题目上下文由数据集提供，未检索外网。
- 每题新建 Agent，短期记忆窗口 24、预算 20,000，避免摘要改写提供的证据。
- 每个数据集分 4 片、每片 100 题；8 路并发；固定 seed=20260906。
- 评分版本 v2，使用规则/轨迹/PublicDatasetScorer；官方参考答案不进入模型提示词。

本次不是两个 Agent 版本的对比，因此不能推导“某次代码改造提升了多少”。也不是该模型默认开启思考模式时的成绩。开发集来自公开 benchmark，结果不能等同于未知任务或未接触测试集的泛化能力。

## 抽查发现

保留本轮原始分数和标签，没有根据模型答案反向修改测试数据。

1. **确有上游标签错误。** `gsm8k:train:3363` 题意是红袜 6、蓝袜 12、黑袜 6、白袜 8，共 32。官方解法把“红袜比白袜少一双”反向算成白袜 4，gold 为 28。模型答 32，在本轮官方标签评分下被判错。已与哈希固定的原始下载核对，非预处理错误。
2. **严格 EM 不等同于语义正确。** `hotpotqa:5ab72a025542992aa3b8c7b8` 的预测 `documentary film` 对比 gold `documentary`，证据完全正确，但答案 EM=0。`hotpotqa:5ae020f5554299025d62a41b` 的 `867 feet` 对比 `867` 也因单位而扣 EM，同时该题存在漏引证据。
3. **答案对，证据仍可能不足。** `hotpotqa:5addf6135542990dbb2f7f23` 正确回答 `genderqueer`，只引用直接支持答案的句子，漏掉另一条官方标注支持句，因此证据 F1=2/3。需要分别看答案与证据指标。
4. **步数预算影响交付。** `gsm8k:train:6403` 的第 4 次计算已经得到 1056，随后因步数耗尽而输出停止占位文本，未形成合规最终答案。这样的失败不能从分母中删去。
5. **也存在真实推理错误。** `gsm8k:train:1113` 遗漏兄长也随时间增长年龄，答 24 而应为 32；`gsm8k:train:1595` 把最初落后 12 分当作领先，答 29 而应为 5。
6. **部分输出不满足格式。** 如 `hotpotqa:5a7642f7554299109176e6e8` 在 JSON 前添加解释文字；当前严格解析将其记为格式错误。应保留严格分数，同时可在另一份诊断报告中单独检查内容，不事后覆盖原成绩。

下一轮有价值的对照是：固定同一批开发题，比较 4 步与 6/8 步预算，并单独诊断输出格式和答案别名；疑似错误标签进入版本化复核清单。完成开发后再使用未运行的冻结测试集。
